# OPTICAL WEATHER v4.2 — release candidate

## Release intent

v4.2 is a focused content release, not another redesign. It packages the reviewed v4.1 curation architecture and programmes 37–43, then broadens the ready-made reservoir shelf without forcing an under-researched programme 44.

## Public-content scope

Expected assembled catalogue:

- 43 authored programmes;
- 383 programme routes;
- 24 ready-made streams / institutional reservoirs.

New authored programmes retained from the reviewed season:

- 37 — Drawn on Film: Ink / Paper / Light
- 38 — Instructions for Living
- 39 — Mexico: Cinema Rescued
- 40 — Korea Before the Wave
- 41 — Japan Before Anime
- 42 — The Camera Finds the Street
- 43 — The Camera Turns Back: Australian Feminist Counter-Images

v4.2 reservoir additions:

- NFSA — Online Collection
- NFSA — Nangamai
- NFSA — Short Films by First Nations Filmmakers
- ACMI — Screen Culture Collection
- NFPF — Films Available for Viewing

The BFI Player reservoir is retained but explicitly labelled UK-only.

## Deliberate non-goals

- no programme 44 until a commission meets the same source and editorial standard as 37–43;
- no visual redesign;
- no CMS/backend/account system;
- no speculative accessibility claims;
- no restructuring of programme 37 solely for code tidiness.

## Release gates

- all module and catalogue tests pass;
- complete assembled catalogue matches the expected counts above;
- all programme ids and ready-made titles remain unique;
- non-YouTube institutional sources retain provenance fields;
- BFI territorial limitation remains visible and fallback search remains available;
- feature branch remains based on current clean main with no unrelated artefacts.

## Deferred research

Programme 44 remains a research competition between:

- electronic image processing / feedback / early video;
- First Nations and Indigenous moving-image practice at programme scale;
- African, South Asian and Middle Eastern archival or experimental cinema.

The next programme is chosen only when the source routes and curatorial argument are strong enough; it is not required for v4.2.
